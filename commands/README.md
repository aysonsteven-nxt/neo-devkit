# Commands

Reference command surface:

```text
@pack-selector recommend
@pack-installer install <pack>
@pack-installer list
@pack-installer remove <pack>
@pack-installer update <pack>
@pack-installer validate

@devkit init
@devkit status
@devkit context
@devkit handoff
@devkit resume
```

The exact invocation mechanism may vary by provider. These commands describe the intended Neo DevKit behavior.
